# Santa Run - North Pole

크리스마스 테마의 픽셀 스타일 런 게임 웹 프로젝트입니다. 메인 화면에서 시작 버튼을 누르면 게임이 시작되고, 선물을 배달하면서 점수와 미션을 달성하는 구조로 구성되어 있습니다.

## 프로젝트 개요

- 메인 화면: 북극 마을/산타 빌리지 분위기의 시작 화면
- 게임 흐름: 시작 -> 배달 러닝 -> 점수/미션/업적 확인 -> 다시 메뉴로 복귀
- 스타일: 그레이스케일 + 픽셀 아트 + 크리스마스 테마 UI
- 기술 스택: HTML, CSS, Vanilla JavaScript

## 주요 기능

- 메인 메뉴 및 건물/작업장/기록 화면
- Google 로그인 버튼 및 프로필 표시
- 선물 배달형 점수 시스템
- 코인/업그레이드/미션/업적
- 스테이지 전환 및 난이도 증가
- 모바일/데스크톱 입력 지원

## 실행 방법

### 1) 로컬 서버로 실행 (권장)

```bash
cd C:/Users/Subin/Desktop/santa_jump
python -m http.server 8000
```

그 다음 브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8000
```

### 2) 파일 직접 열기

`index.html`을 브라우저로 직접 열어도 동작은 하지만, Google 로그인은 제한될 수 있습니다.

## 주의사항

### Google 로그인

이 프로젝트는 Google Identity Services의 OAuth 클라이언트 ID를 사용합니다.

- Google Cloud Console에서 승인된 JavaScript 원본에 `http://localhost:8000` 등을 등록해야 합니다.
- `file://` 경로로 직접 열면 로그인이 동작하지 않을 수 있습니다.
- 로그인은 브라우저에서 프로필 이름/사진을 표시하는 용도이며, 서버로 토큰을 전송하거나 검증하지 않습니다.
- 게임 점수, 업적, 로그인 상태는 로컬 브라우저 저장소에만 저장됩니다.

## 파일 구조

```text
santa_jump/
├── index.html      # 메인 페이지 및 UI 구조
├── game.js         # 게임 로직, 상태 관리, 입력 처리
├── styles.css      # 별도 스타일 시트 (참조용/보조 스타일)
├── README.md       # 프로젝트 설명
└── .git            # Git 저장소
```

## 게임 조작

- 좌측 클릭 / `Z`: 선물 발사
- 우측 클릭 / `Space`, `ArrowUp`: 점프
- `P`: 일시정지

## 개발 메모

- 프로젝트는 정적 웹 페이지 구조를 기반으로 동작합니다.
- 메인 화면의 장식 요소와 게임 화면을 함께 유지하면서 시작 플로우가 자연스럽게 연결되도록 구성되어 있습니다.
- 현재 구조는 로컬 데모용으로 적합하며, 서버 연동이 필요한 기능은 별도 백엔드가 필요합니다.
