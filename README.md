# Santa Run - North Pole

크리스마스 테마의 픽셀 스타일 런 게임 웹 프로젝트입니다. 메인 화면에서 시작 버튼을 누르면 게임이 시작되고, 선물을 배달하면서 점수와 미션을 달성하는 구조로 구성되어 있습니다.

## 프로젝트 개요

- 메인 화면: 북극 마을/산타 빌리지 분위기의 시작 화면
- 게임 흐름: 시작 -> 배달 러닝 -> 점수/미션/업적 확인 -> 다시 메뉴로 복귀
- 스타일: 그레이스케일 + 픽셀 아트 + 크리스마스 테마 UI
- 기술 스택: HTML, CSS, Vanilla JavaScript

## 주요 기능

- 메인 메뉴 및 건물/작업장/기록 화면
- Google 로그인 및 계정별 진행 상황 저장
- Google 계정별 게임 진행 상황 저장/불러오기
- 선물 배달형 점수 시스템
- 코인/업그레이드/미션/업적
- 스테이지 전환 및 난이도 증가
- 모바일/데스크톱 입력 지원

## 실행 방법

`index.html`을 브라우저로 직접 열어도 동작은 하지만, Google 로그인은 제한될 수 있습니다.

## 주의사항

### Google 로그인

게임 진행 상황은 Google Drive의 비공개 앱 데이터 영역(`appDataFolder`)에 저장됩니다. 별도 서버는 필요하지 않으며, 최초 로그인 시 기존 브라우저 저장 진행 상황이 해당 Google 계정으로 복사됩니다. 이후에는 게임 종료 기록과 업그레이드가 계정에 동기화됩니다.

1. Google Cloud Console에서 프로젝트를 만들고 **Google Drive API**를 활성화합니다.
2. OAuth 동의 화면을 설정하고 `openid`, `email`, `https://www.googleapis.com/auth/drive.appdata` 범위를 허용합니다. 테스트 모드에서는 사용할 Google 계정을 테스트 사용자에 추가합니다.
3. OAuth 클라이언트 ID(웹 애플리케이션)를 만들고 승인된 JavaScript 원본에 `http://localhost:8000` 및 배포 사이트 원본을 등록합니다.
4. [index.html](./index.html)의 `window.SANTA_GOOGLE_CLIENT_ID` 값을 발급받은 클라이언트 ID로 바꿉니다. OAuth 클라이언트 ID는 브라우저에 공개되는 값이며, 클라이언트 시크릿은 추가하지 마세요.
5. 로컬 서버 또는 HTTPS 배포 사이트에서 실행한 뒤 **SAVE WITH GOOGLE**을 눌러 로그인합니다. `file://` 경로로 직접 열면 로그인이 동작하지 않을 수 있습니다.

게임 진행 상황은 기기 로컬에도 캐시됩니다. 페이지를 새로 열면 **SAVE WITH GOOGLE**을 다시 눌러 계정의 최신 저장 내용을 불러오세요. Google 로그아웃은 실행 중인 게임을 끝낸 뒤 버튼을 다시 눌러 진행합니다.

## 파일 구조

```text
santa_jump/
├── index.html      # 메인 페이지 및 UI 구조
├── game.js         # 게임 로직, 상태 관리, 입력 처리
├── styles.css      # 별도 스타일 시트 (참조용/보조 스타일)
├── README.md       # 프로젝트 설명
└── .git            # Git 저장소
```

## 게임 조작

- 메인 화면: `←` / `→`로 산타 이동, 건물 앞에서 `↑` 또는 `Enter`로 입장
- 좌측 클릭 / `Z`: 선물 발사
- 우측 클릭 / `Space`, `ArrowUp`: 점프
- `P`: 일시정지

## 개발 메모

- 프로젝트는 정적 웹 페이지 구조를 기반으로 동작합니다.
- 메인 화면의 장식 요소와 게임 화면을 함께 유지하면서 시작 플로우가 자연스럽게 연결되도록 구성되어 있습니다.
- 계정별 동기화는 Google Drive API를 사용하며 별도 백엔드는 필요하지 않습니다.
